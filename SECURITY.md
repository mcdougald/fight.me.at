# Security policy

Found a vulnerability affecting fight.me.at (or any `*.me.at` app, trev.fyi, or their
shared backend)? Email **contact@me.at** — a proof-of-concept beats a scanner dump. Solo-operated
personal fleet: expect an acknowledgement within a few days and a best-effort fix; credit given if
wanted, no bounty program. Please don't test with real users' data, run DoS, or disclose publicly
before a fix ships. Every app also serves `/.well-known/security.txt` (RFC 9116).
